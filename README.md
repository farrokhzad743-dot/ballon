# وب‌سایت شرکت تعاونی عشایری کوه نور کهگیلویه

نسخه نهایی ایستای وب‌سایت برای انتشار روی GitHub Pages و دامنه `tavonikohnoor.ir`.

## ساختار
- `index.html` — صفحه اصلی و SEO
- `style.css` — ظاهر و واکنش‌گرایی
- `script.js` — رفتار صفحه، اخبار، گالری و اسناد
- `` — تمام تصاویر اخبار به‌صورت محلی
- `site-header.jpg` — هدر
- `eitaa-logo.png` — لوگوی ایتا
- `asasname.pdf` — اساسنامه
- `robots.txt` و `sitemap.xml` — آماده برای موتورهای جست‌وجو
- `CNAME` — دامنه اصلی `tavonikohnoor.ir`

## نکته مهم
این نسخه عمداً هیچ پنل مدیریت، Supabase، API، Proxy یا لینک ImgBB ندارد. محتوای سایت به‌صورت دستی در همین فایل‌های استاتیک مدیریت می‌شود.

برای افزودن یا تغییر خبر، تصاویر را در `` قرار دهید و آرایه `news` در `script.js` را ویرایش کنید.
